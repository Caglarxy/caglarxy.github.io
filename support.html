Support

Questions, feedback, or a bug to report?

LPF Organizer and LPF Explorer are personal projects, and I welcome suggestions and reports that help improve them.

Reporting a problem

If you discover a bug, a short description with the following information would be helpful:

  • Your macOS version
  • The application name and version
  • A brief description of the problem
  • The steps needed to reproduce it, if possible

Please send your report to info@lpf.one.

Support is offered on a best-effort basis. There are no guaranteed response times, bug fixes, or future updates.
